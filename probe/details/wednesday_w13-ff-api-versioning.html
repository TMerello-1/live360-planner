W13 Fast Focus: API Versioning

09/16/2026

1:45pm - 2:05pm

Level: Intermediate

Philip Japikse

Microsoft MVP, ASPInsider, MCSD, PSM II, PSD and PST

CTO/Chief Architect, Author, Speaker

Pintas & Mullins

APIs don’t stay the same for long. As your applications evolve, your APIs need to evolve with them—but breaking existing consumers is rarely an option. That’s where versioning comes in.

In this rapid-fire Fast Focus session, Philip Japikse explains why API versioning is essential for modern applications and demonstrates how to quickly implement versioning in ASP.NET Core using proven tools and techniques. You’ll see how to introduce versioning into your APIs in a way that keeps your services flexible, maintainable, and friendly to existing clients.

Whether you’re building new APIs or maintaining existing services, you’ll walk away with practical strategies you can immediately apply to your ASP.NET Core projects.

You will learn:

  • Why API versioning matters and when you should introduce it
  • Common API versioning strategies used in real-world RESTful services
  • How to implement API versioning in ASP.NET Core quickly using available tooling

All the essentials—delivered in just 20 minutes.
